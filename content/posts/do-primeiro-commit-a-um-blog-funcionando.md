Começar pequeno ajuda a colocar um projeto em movimento. Agora as publicações deste blog são arquivos Markdown no próprio repositório.

## Como publicar

1. Copiar o template.
2. Preencher os metadados e escrever o texto.
3. Fazer commit e gerar uma nova versão do site.

```bash
npm run build
```

O resultado é um site estático que pode ser hospedado sem API ou banco de dados.
